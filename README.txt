# DesignHub demo website

A responsive digital-design marketplace front-end built with plain HTML, CSS and JavaScript.

## Run it
1. Download and extract `DesignHub-Website.zip`.
2. Open the `designhub_website` folder.
3. Double-click `index.html` to open it in Chrome, Edge, Firefox, or another browser.
4. You can also edit `index.html`, `style.css`, and `script.js` with Visual Studio Code.

## Features in this demo
- Responsive home page and navigation
- Product grid with sample design cards
- Search, category filters, and price sorting
- Product detail popup
- Add-to-cart drawer with total
- Wishlist toggle
- Seller profile demo form
- Newsletter form demo
- Mobile navigation

## Important before launching for real customers
This is a front-end demo. It does NOT yet store uploaded designs, create real customer accounts, deliver paid downloads, or process payments. To sell for real, connect a backend/database, secure file storage, authentication, order records, and a payment provider available for your business in Pakistan. Replace all sample products and prices with your own work, add clear license/refund terms, and configure your own social links and contact details.
